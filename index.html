How a CDN Works

A Content Delivery Network is a collection of distributed servers that cache website files closer to users. When a visitor requests a page, the CDN can provide cached content from an edge server instead of contacting the original server every time.

Cache Hit

A cache hit happens when the requested content is already stored on the CDN's edge server. The CDN can immediately return the content without contacting the origin server.

Origin Fetch

An origin fetch happens when the requested content is not available in the edge cache. The CDN contacts the origin server, retrieves the content, and can then cache it.

Edge Server

Edge servers are distributed across different geographic locations. They allow users to receive content from a location closer to them.
